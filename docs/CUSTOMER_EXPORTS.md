# Customer exports

Help a workspace administrator export the customer list.

- Show customer name, company, email, status and created date.
- Let the user search customers and filter by status.
- The main action is “Export customers”. Export CSV using the active filters.
- Before starting, show the workspace, matching row count and included columns.
- Only workspace administrators can export. Other members see a clear explanation.
- Show a useful empty state when no customers match, and a clear message if export fails.
- Keep private notes, payment details, passwords and tokens out of the exported file.
- Use the project's shared visual and security rules.

The website preview uses sample data. Actual export, permissions and filtering require backend implementation; do not present a visual preview as a working service.
