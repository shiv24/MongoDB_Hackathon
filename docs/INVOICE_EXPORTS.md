# Invoice exports

Help a workspace administrator export invoices from the billing page.

- Show invoice number, customer, amount, currency, status and issue date.
- Let the user filter by paid/unpaid status and date range.
- The main action is “Export invoices”. Export CSV using the active filters.
- Before starting, show the workspace, matching invoice count and included columns.
- Only workspace administrators can export. Do not include payment-card details or internal notes.
- Show a helpful empty state, a pending state and a clear failure message.
- Use the project's shared visual and security rules.

The website preview uses sample data. Actual export, permissions and filtering require backend implementation.
